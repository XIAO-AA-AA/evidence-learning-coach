# Assessment by goal

Set the rubric before the first attempt, keep its version and use the same version when scoring. A rubric contains an identifier, total points, pass points and observable criteria. For an official assessment use a verified applicable rubric when available. Otherwise label the rubric as coach-authored and the score as an estimate.

## Recall and exam-style writing

Award independent points for correct concepts and required items. Semantic equivalents count; preserve exact technical terms only where the meaning or marking depends on them. Do not demand wording identical to a teaching handout merely because it differs. Keep completion, accuracy and time separate.

For case answers, distinguish explicit facts, supported process inference and insufficient evidence. Evaluate the given source rather than mechanically adopting a flawed answer key. Do not equate “not mentioned” with “not done”. Record an inconsistent key or ambiguous question as provisional and clarify before assessing independent performance.

## Quantitative problem solving

Assess model choice, assumptions, formula, substitution, calculation, units, sign and interpretation. A correct final number with an invalid argument is not full process credit. A correct method with a calculation slip can receive partial credit. Retain precision until the last step; avoid ambiguous time conventions and inconsistent data.

## Programming and procedures

Evaluate observable acceptance criteria, execution evidence, tests, explanation and transfer to a changed requirement. Separate assisted code, self-written code and independently debugged behavior. State whether code was actually executed. A submitted file is not proof of competence, and an agent's passing tests do not prove the learner could reproduce the skill.

## Languages and open-ended work

Use an explicit analytic rubric: task completion, correctness, clarity and relevant domain dimensions. Feedback may improve a draft without proving independent ability; later use a different prompt. Do not overcorrect acceptable alternatives or grade stylistic preference as factual error. If recording or observing a skill is unavailable, grade only the available evidence.

## Complete feedback

1. Result with the basis and uncertainty, not false precision.
2. Correct points and partial-credit points.
3. Every material error and missing item, grouped to avoid repetition.
4. The minimal correction or short teaching needed.
5. A later retest plan and the evidence needed for an upgrade.

Error tags: `recall-gap`, `concept`, `procedure`, `calculation`, `terminology`, `evidence`, `omission`, `expression`, `unknown`. Tags support planning and can be combined. Do not infer a cause the learner has not demonstrated.
