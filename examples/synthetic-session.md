# 虚构学习者的完整闭环

此示例由项目作者虚构，不代表真实学习者或受控实验。

目标：独立进行分数加法。来源：原创练习。

## 第一天：独立首答

教练预先设定评分：正确通分2分、算术1分、解释1分；4分通过。

题目：计算1/3 + 1/4，并说明过程。

学习者首答：`1/3 + 1/4 = 2/7，因为分子分母分别相加。`

评分：0/4；确认的概念错误。保留首答。反馈：分母不同表示单位不同，先统一为十二分之一；3/12 + 4/12 = 7/12。

## 当场修补

学习者看过反馈后答：`先通分，1/3 = 4/12，1/4 = 3/12，所以7/12。`

记录 assistance 为 `feedback`，不能计为独立掌握。首答依然保存；新答案写入新的 attempt。因为先前独立错误尚未被新独立成功解决，队列仍标记 needs-practice。

## 第二天：不同题、无提示复测

超过配置中的延迟间隔后，给另一道未见变式：`2/5 + 1/6`。学习者独立完成 `17/30` 并解释，评分4/4。此时标记 delayed-pass。

隔天再用另一个变式验证，成功后才获得 stable-evidence。之后若独立出错，则重新安排练习。

## 存档与续接

用户要求存档后，保存每次原答与单独评分，在 latest-session-notes.md 写明：

> 已完成一次不同变式的独立延迟复测。下一次使用分母有公因数的分数加法验证迁移；暂不学习新运算。首答与当场修补已分别保存。

新对话依据这一位置继续，不重讲整章。
